# My portfolio on Workana

Senior full-stack portfolio for **Suci Rahmawati** — multi-page Next.js site with a purposeful Three.js hero, case studies, and a clear hire path.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Framer Motion
- React Three Fiber + Drei

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Routes

- `/` — hero + selected work
- `/work` — project index
- `/work/[slug]` — case studies
- `/approach` — process
- `/about` — bio
- `/contact` — inquiry

## Deploy

Push to GitHub and connect the repo to Vercel for production hosting.
